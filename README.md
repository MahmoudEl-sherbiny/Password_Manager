# 🔐 Password Manager App

A secure and user-friendly Python GUI application that helps you generate, store, and retrieve passwords efficiently.

## 🧰 Features

- ✅ Generate strong random passwords with letters, numbers, and symbols
- ✅ Save credentials (website, email, password) to a local JSON file
- ✅ Search stored credentials by website name
- ✅ Automatically copy generated password to clipboard
- ✅ Clean and simple Tkinter-based interface

## 💻 Technologies Used

- Python
- `tkinter` for GUI
- `json` for data storage
- `pyperclip` for clipboard support
- `random` for password generation

## 📂 Files Included

- `main.py` - Main application logic
- `logo.png` - Logo displayed in the GUI
- `Data.json` - Stores saved credentials (automatically created)
